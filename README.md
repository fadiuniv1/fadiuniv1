## 🚀 Featured project — contextpack

**Pack a repository into a clean, token-budgeted Markdown file you can paste into any LLM or coding agent.**

- No API keys. No uploads. No runtime dependencies — everything runs locally.
- Respects nested .gitignore and .ignore rules.
- Ranks useful files first: source → docs → config → tests.
- Redacts common secrets: API_KEY values, sk- and ghp_ tokens, AWS keys, JWTs, private key blocks.
- **--diff** mode packs only changed files — useful for code-review prompts.
- MIT licensed. Requires Node.js 18+.

~~~bash
npx contextpack-cli . --budget 8000 -o context.md
npx contextpack-cli . --diff main --focus 'src/**' -o pr-context.md
~~~
